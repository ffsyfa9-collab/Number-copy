# NumQueue - সিরিয়াল নম্বর কপিয়ার ও ফ্লোটিং উইজেট

NumQueue একটি শক্তিশালী অ্যান্ড্রয়েড অ্যাপ্লিকেশন যেখানে সারিবদ্ধভাবে ফোন নম্বর সংরক্ষণ করা যায় এবং অন-স্ক্রিন ফ্লোটিং আইকনের মাধ্যমে অন্য অ্যাপে থাকাকালীনও এক ট্যাপে নম্বর কপি করা যায় এবং স্বয়ংক্রিয়ভাবে মুছে যায়।

---

## প্রধান সুবিধাসমূহ (Key Features)

1. **সারিবদ্ধ নম্বর ইনপুট ও সংরক্ষণ (Sequential Number Queue):**
   - প্রতি লাইনে একটি করে নম্বর পেস্ট বা টাইপ করে সংরক্ষণ।
   - স্বয়ংক্রিয় FIFO ক্রমধারা (#১, #২, #৩...)।
   - নোট/গ্রুপ নাম যোগ করার সুবিধা।

2. **অন-স্ক্রিন ফ্লোটিং উইজেট (Floating Copier Overlay):**
   - হোয়াটসঅ্যাপ, মেসেজিং বা ডায়ালার ব্যবহারের সময়ও স্ক্রিনে ড্র্যাগেবল বাবল দেখা যায়।
   - লাইভ কাউন্টার ব্যাজ (কতটি নম্বর বাকি আছে)।
   - বাবলে এক ট্যাপেই পরবর্তী নম্বর ক্লিপবোর্ডে কপি ও সারি থেকে মুছে ফেলা।

3. **ডাটাবেস ব্যাকআপ ও রিস্টোর (Database Backup & Restore):**
   - সম্পূর্ণ ডাটাবেস JSON ফাইল আকারে এক্সপোর্ট ও শেয়ার (গুগল ড্রাইভ, টেলিগ্রাম, ইত্যাদি)।
   - যেকোনো সময় ব্যাকআপ ফাইল থেকে রিস্টোর করার সুবিধা।
   - সাধারণ টেক্সট তালিকা আকারে এক ক্লিকে সব নম্বর কপি/শেয়ার।
   - হিস্ট্রি থেকে দুর্ঘটনাবশত ডিলিট হওয়া নম্বর পুনরায় সারিতে ফিরিয়ে আনার ব্যবস্থা।

## GitHub Actions - Auto APK Build (স্বয়ংক্রিয় APK তৈরি)

এই প্রজেক্টে GitHub Actions CI/CD যুক্ত করা হয়েছে(`.github/workflows/build-apk.yml`)।

### যেভাবে APK ডাউনলোড করবেন:
1. কোড GitHub রিপোজিটরিতে `main` বা `master` ব্রাঞ্চে push করলেই স্বয়ংক্রিয়ভাবে APK বিল্ড শুরু হবে।
2. অথবা GitHub রিপোজিটরির **Actions** ট্যাবে যান:
   - বাঁদিকের তালিকা থেকে **Build Android APK** নির্বাচন করুন।
   - **Run workflow** বাটনে ক্লিক করুন।
3. বিল্ড সফলভাবে সম্পন্ন হলে উক্ত রানটি ওপেন করে নিচের **Artifacts** সেকশন থেকে **`NumQueue-debug-apk`** ডাউনলোড করে ফোনে ইন্সটল করতে পারবেন।
4. কোনো রিলিজ ট্যাগ (যেমন: `v1.0.0`) পুশ করলে স্বয়ংক্রিয়ভাবে GitHub Release তৈরি হবে এবং তাতে APK যুক্ত থাকবে।
